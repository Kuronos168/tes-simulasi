Halaman 1 · Depan

Materi 1–4: deskriptif, frekuensi, peluang, nilai harapan

  • Deskriptif = meringkas data (tabel, grafik, rata-rata). Inferensia = sampel → simpulkan populasi.
  • Populasi (population) → parameter: μ, σ, p
  • Sampel (sample) → statistik: x̄, s, p̂ P–P, S–S
  • Statistika = seni mengumpulkan, mengolah, menafsirkan data jadi informasi

  • Mean x̄ = Σx / n · Median: URUTKAN dulu, letak (n+1)/2 · Modus: paling sering (bisa 2: “3 dan 8”)
  • Ada pencilan (outlier) → pakai median
  • Range = maks − min
  • Varians sampel s² = Σ(x − x̄)² / (n − 1) · populasi: bagi n
  • Simpangan baku (standard deviation) s = √s²
  • Simpangan rata-rata SR = Σ|x − x̄| / n (MAD)
  • Koef. variasi KV = s / x̄ × 100% → KV kecil = risiko relatif kecil
  • Mean gabungan (n₁x̄₁ + n₂x̄₂) / (n₁ + n₂)
  • Kalkulator: sx = sampel, σx = populasi
  • Pareto 80/20: 20% pelanggan → 80% omzet

  • URUTKAN dulu. Letak = i(n + 1) / k, k = 4 (Q), 10 (D), 100 (P)
  • Letak pecahan, mis. 3,3 → x₃ + 0,3 × (x₄ − x₃)
  • Contoh n = 8: D2 letak 1,8; Q3 letak 6,75
  • Excel: QUARTILE.EXC, PERCENTILE.EXC (cocok rumus n+1)

  • Kelas 40–49: batas bawah/atas = 40 / 49 · tepi = 39,5 / 49,5
  • Titik tengah (40 + 49)/2 = 44,5
  • Panjang kelas = tepi atas − tepi bawah = 49 − 40 + 1 = 10 bukan 9
  • Σf = n · frek. relatif = f/n × 100%
  • Kumulatif kurang dari → tepi ATAS (≤) · lebih dari → tepi BAWAH (≥)
  • Sturges k = 1 + 3,3 log n log, bukan ln
  • Panjang kelas = range / k → bulatkan KE ATAS
  • Mean berkelompok Σ(f·m) / Σf, m = titik tengah
  • Median berkelompok Tb + ((n/2 − F)/f) × p; Tb = tepi bawah, F = kumulatif sebelum kelas median

  • Komplemen P(tidak A) = 1 − P(A) · “minimal 1” = 1 − P(0)
  • DAN (independen) → KALI · bertahap → kali berantai
  • ATAU → P(A) + P(B) − P(A∩B); saling lepas → irisan = 0
  • Bersyarat P(A|B) = P(A∩B) / P(B) → penyebut = kelompok B saja
  • Kombinasi C(n,r) = n! / (r!(n − r)!) · kalkulator nCr = SHIFT ÷
  • Tanpa pengembalian (without replacement) → C(…) × C(…) / C(total)

  • E(X) = Σ x·P(x) (expected value) · rugi = negatif
  • Var(X) = E(X²) − [E(X)]², E(X²) = Σ x²·P(x)
  • Cuma 2 nilai: Var = p(1 − p)(x₁ − x₂)²
  • Banyak kejadian: E = n × p (200 × 4% = 8)
  • Y = aX + b: E(Y) = aE(X) + b, σY = |a|σX (b tidak ikut)
  • Independen: E dijumlah, Var dijumlah → σ tidak dijumlah langsung
  • Portofolio: Σ bobot × return
  • Standar error SE = σ/√n · proporsi √(p(1 − p)/n)

Data kontinu, diketahui μ dan σNormal

  • Bernoulli: E = p, E(X²) = p, Var = p(1 − p)
  • Binomial: C(n,x) · pˣ · (1 − p)ⁿ⁻ˣ → “sukses pangkat sukses, gagal pangkat gagal”
  • Binomial: E = np, Var = np(1 − p), σ = √Var
  • Hipergeometrik: C(K,x) · C(N−K, n−x) / C(N,n); N total, K sukses, n diambil
  • Poisson: e^(−λ) · λˣ / x!; E = Var = λ; 0! = 1
  • Sesuaikan λ dengan interval: 6/jam → 15 menit λ = 1,5
  • P(0) Poisson = e^(−λ) · kalkulator eˣ = SHIFT ln
  • Casio: setelah pangkat / eˣ tekan ► sebelum ×
  • Excel: BINOM.DIST(x;n;p;0) · POISSON.DIST(x;λ;0) · HYPGEOM.DIST(x;n;K;N;0) · 0 = tepat, 1 = ≤ x

  • Z = (X − μ) / σ · rata-rata sampel: Z = (x̄ − μ) / (σ/√n) pakai SE
  • Tabel kumulatif = luas KIRI: P(X < a) = Φ(z)
  • P(X > a) = 1 − Φ(z) · antara: Φ(z₂) − Φ(z₁) · Φ(−z) = 1 − Φ(z)
  • Empiris: μ ± 1σ / 2σ / 3σ = 68% / 95% / 99,7% (0,6826 / 0,9544 / 0,9974)
  • Terbalik: X = μ + z·σ; 10% teratas → luas kiri 0,90 → z = 1,28
  • z penting: 10% → 1,28 · 5% → 1,645 · 2,5% → 1,96 · 0,5% → 2,58
  • σ besar → kurva landai & lebar · simetris, mean = median = modus, luas = 1
  • Normal ≈ binomial jika np ≥ 5 DAN n(1 − p) ≥ 5
  • Sketsa kurva & arsir daerah yang ditanya sebelum baca tabel
  • Excel: NORM.DIST(x;μ;σ;1) · NORM.INV(luas;μ;σ)

  • confidence interval = estimasi ± MoE, MoE = z × SE
  • Rata-rata: x̄ ± z · σ/√n
  • Proporsi: p̂ ± z · √(p̂(1 − p̂)/n), p̂ = x/n
  • Tingkat kepercayaan (confidence level): 90% → 1,645 · 95% → 1,96 · 99% → 2,58
  • Kepercayaan ↑ → lebar · n ↑ → sempit · σ ↑ → lebar
  • Ukuran sampel n = (z·σ / E)² → bulatkan KE ATAS
  • Dari interval: x̄ = titik tengah, MoE = ½ lebar, SE = MoE/z, σ = SE·√n
  • Tafsiran: “95% interval dari sampel berulang memuat μ” (bukan 95% data)
  • Proporsi: n = z²·p(1 − p)/E², p belum tahu → 0,5
  • Excel: CONFIDENCE.NORM(α;σ;n) = MoE

  • Tipe I: tolak H0 padahal BENAR → peluang α · Tipe II: gagal tolak H0 padahal SALAH → β
  • α = 0,05 ↔ kepercayaan 95% · α ↓ → β ↑ · n ↑ → keduanya ↓
  • Tidak bias (unbiased): E(estimator) = parameter
  • Efisien: varians terkecil · Konsisten: n ↑ → mendekati parameter
  • Pilih: saring yang tidak bias → ambil varians terkecil
